## 0. 文件目的與定位

這份文件從**玩 Minecraft 的角度**，盤點遊戲裡存在的主要玩法、互動與機制，並對照 BlockAgent 目前的支援度。

**核心原則**：

- **圖鑑，不是承諾清單**：列在這裡只代表「Minecraft 裡有這種玩法」，**不代表全部都必須實作**。未來要擴充能力時，直接從這份文件挑選想補的項目，再寫進 `docs/SPEC.md` 展開技術細節。
- **只談玩家能不能做到，不談實作細節**：不寫 Java 類別、Mixin、封包或 MCP schema；那些由 `docs/SPEC.md` 負責。
- **按遊戲玩法分類，不按工具名稱分類**：避免被現有工具清單綁住視野，漏看空白地帶。

### 狀態定義

| 狀態 | 意思 |
|---|---|
| ✅ 已支援 | 一般遊玩流程完整，沒有明顯斷點 |
| 🟡 部分支援 | 做得到一部分，或僅涵蓋部分情境；註明目前的範圍與限制 |
| ⬜ 未支援 | 遊戲裡有此玩法，目前尚未實作(不預設必須實作) |
| 🚫 原則不做 | 基於安全底線或專案架構原則不實作(如管理員方塊、創造模式飛行、視覺截圖) |

### 生存進程卡點

上面的領域是平行列出的，看不出哪個缺口會擋住遊戲往前推進。下表照一般單人從零推進的進程排列，每一階段只寫**最先卡住的地方**；多人世界若陪朋友跳階或借用朋友的設施(例如穿鐵裝陪朋友進地獄)，可直接挑對應的使用端能力，不一定要等前面階段補齊。

| 階段 | 目標 | 目前狀態 | 第一個卡點 |
|---|---|---|---|
| 起步 | 木製與石製工具、第一晚過夜、床 | ✅ 通 | — |
| 定居 | 放得下設施的房子、穩定的食物(農田或動物)、箱子 | ✅ 通 | 只有零星限制(雙格家具不能進藍圖，見 3.6) |
| 鐵器 | 鐵鎬、鐵劍、鐵甲、盾牌 | ✅ 通 | — |
| 鑽石 | 往深層找到鑽石 | ✅ 通 | —(`dig_tunnel` 支援階梯下挖、水平礦道、自動插火把、安全前瞻與 `tool_match` 時運開採) |
| 附魔 | 附魔裝備、修理與合併 | ✅ 通 | —(`enchant`、`anvil`、`grindstone` 全數支援，可驗證 30 級書架陣) |
| 地獄 | 進地獄、拿到烈焰棒與地獄疙瘩 | ✅ 通 | —(`nether_portal` 蓋門點火與進出；`get_surroundings` 列出地獄磚、生怪磚當堡壘線索；沒弓也能近戰烈焰使者；地獄裡的地獄疙瘩可用 `mine` 採) |
| 釀造 | 抗火、夜視、治癒等藥水 | 🟡 卡住 | 不能用釀造台(3.9)(已能長按飲用現成藥水、牛奶與蜂蜜瓶) |
| 終界 | 找到要塞、開終界門 | ⬜ 卡住 | 不能瞄準投擲終界之眼(第 2 節、3.12) |
| 終界之後 | 終界城、鞘翅 | ⬜ 卡住 | 終界龍目前會避開(3.10)；不能用鞘翅滑翔(3.1) |

目前最前面的卡點已推進到「釀造」階段的釀造台(3.9)。

## 2. 底層通用能力(打通後可同時解鎖多種玩法)

這幾個不是單一玩法，而是**跨領域的基礎操作能力**。過去若缺底層能力，往往會被迫替每個小場景單獨加特化工具；挑功能時可優先留意這一層：

| 底層能力 | 狀態 | 目前狀況 | 若補齊可同時解鎖的玩法 |
|---|---|---|---|
| **長按使用/蓄力/飲用** | 🟡 | `eat` 已涵蓋所有食物與飲品(藥水、牛奶桶、蜂蜜瓶)並回報狀態效果變化；弓/盾/弩仍僅內建於戰鬥系統，`use_item` 不長按 | 主動拉弓/射弩/丟三叉戟、吹山羊角、望遠鏡、刷子考古 |
| **瞄準方向投擲** | ⬜ | `use_item` 帶座標只限 4.5 格觸及範圍，不帶座標無法指定方向/仰角 | 丟終界珍珠逃生/跨地形、丟終界之眼找要塞、丟噴濺/滯留藥水、丟雪球/雞蛋 |
| **蹲下貼放與完整方塊狀態** | ✅ | `place_block` 支援 `facing`、`half`(上下半磚、倒置樓梯、活板門)與 `sneak=true` 蹲下貼放可互動方塊，並維持所有權防線 | 已解鎖箱子上放漏斗、熔爐上疊箱子、工作台旁插火把、精細屋頂/階梯/紅石佈局 |
| **工作站介面操作框架** | 🟡 | 已建立共用的開啟/同步/恢復工作站框架(`ContainerTask`)，支援工作台、箱子類、普通熔爐、高爐、煙燻爐、書台、附魔台、鐵砧與砂輪 | 切石機、鍛造台、釀造台、漏斗/發射器 |
| **讀取方塊實體資料** | 🟡 | 已可讀告示牌雙面文字、物品展示框內容、書台上的書與熔爐內部進度/內容 | 看釀造台內部狀態、看蜂箱蜂蜜量、看堆肥桶層數 |
| **依屬性指定物品** | ✅ | `equip`/`drop`/`eat`/`use_item` 支援 `match`，`chest(put/take)` 支援 `id[條件]` 篩選附魔、儲存附魔、藥水、名稱與高低耐久 | 已解鎖精準取放附魔書/藥水、優先裝備高耐久裝備、丟掉殘血工具 |
| **副手(Offhand)一致存取** | ✅ | `craft`、`equip`、`eat`、`smelt`、`chest(put)`、`drop`、`use_item`、`place_block` 皆納入副手檢查與自動切換/換回 | 已避免物品在副手時誤判缺料或無法存取 |

## 3. 各領域遊戲玩法全清單

### 3.1 基礎移動、探索與交通

| 玩家想做的事 | 狀態 | 現況與已知限制 |
|---|---|---|
| 行走、跳躍、爬坡、跨小水溝、開門通過 | ✅ | `goto`、`goto_block`；含室外淺水自動上岸與尋路避怪 |
| 游泳、深水潛水與自動上浮換氣 | 🟡 | 有溺水反射自動往上游/找空氣格，但沒有主動水下探索或水下建築作業流程 |
| 攀爬梯子、藤蔓、鷹架 | 🟡 | 尋路會利用現有梯子/藤蔓，但沒有主動搭鷹架柱或垂降作業 |
| 往未探索區塊遠行、找特定生態域或結構 | 🟡 | `get_surroundings` 會列出已載入區塊的鄰近生態域方向；`mine(search=true)` 可往外找方塊，但無通用的「沿方向探索」或結構定位 |
| 乘坐其他玩家駕駛的船或礦車 | ✅ | `mount`、`dismount` |
| **自己放船、划船渡河/跨海、上岸收回船** | ⬜ | `mount` 明確只當乘客，不會自己操船 |
| **騎馬、驢、騾、駱駝、熾足獸(含上鞍與騎乘移動)** | ⬜ | 未支援駕馭坐騎；且已馴服馬匹目前被保護規則擋下 |
| **鋪設鐵軌並搭礦車移動/運物** | ⬜ | 無鐵軌鋪設與礦車推動/乘車控制 |
| **裝備鞘翅(Elytra)滑翔與煙火推進** | ⬜ | 未支援飛行控制與空中煙火加速 |
| **使用終界珍珠瞬移跨地形或脫困** | ⬜ | 缺瞄準方向投擲能力 |
| **使用地標與地圖導航(地圖、羅盤、磁石)** | ⬜ | 可靠座標與 `memory_*` 導航；無法查看地圖內容或對磁石綁定羅盤 |
| **使用床設定重生點 / 使用重生錨(地獄)** | 🟡 | 主世界睡床可設重生點(`sleep`)；地獄重生錨充能與設定未支援 |

### 3.2 採集、挖掘與方塊基本操作

| 玩家想做的事 | 狀態 | 現況與已知限制 |
|---|---|---|
| 挖掘單格方塊、砍樹、採掘礦石並撿掉落物 | ✅ | `break_block`、`mine`(支援自動換最佳工具、不拿劍挖方塊、挖完撿最後掉落物) |
| 範圍清除天然方塊(整地、清樹葉、清雜草) | ✅ | `clear_area` |
| 系統性地下挖礦(階梯下挖、水平/魚骨礦道、沿途插火把) | ✅ | `dig_tunnel` 支援 1×3 階梯下挖與 1×2 水平礦道，每步前瞻岩漿/水流/深坑/受保護方塊/`stop_on` 礦脈，依 `torch_every` 自動插火把(無火把限短距 12 格)並回報沿途礦脈清單 |
| 使用附魔工具策略(絲綢之觸採原礦/玻璃/冰、時運挖鑽石) | ✅ | `break_block`、`mine`、`dig_tunnel` 支援 `tool_match` 指定附魔或耐久偏好；`mine` 僅對目標方塊強制選用指定附魔工具，開路石材仍用普通最快工具 |
| 放置單格方塊與指定朝向(樓梯、熔爐、箱子、漏斗、牆火把、原木軸) | ✅ | `place_block`(含 `facing` 模擬與驗證) |
| 蹲下貼放方塊(對箱子/熔爐/工作台/漏斗貼放) | ✅ | `place_block(sneak=true)`；放完自動放開蹲下，且維持不可覆蓋/疊合他人方塊的保護 |
| 指定細部放置狀態(上半磚/下半磚、倒置樓梯、活板門上下) | ✅ | `place_block(half=bottom\|top)` 可搭配 `facing` 模擬與驗證；藍圖亦支援完整方塊狀態 |
| 用桶子撈水/倒水、撈岩漿/倒岩漿、做無限水、澆黑曜石 | 🟡 | `use_item` 可撈/倒水源並避開他人可燃物；但無法用桶子操作煉藥鍋以外的精細流體控管(如細雪桶、裝魚/蠑螈桶) |
| 用工具轉換方塊(削樹皮、鏟草徑、去蠟/去氧化、刻南瓜、熄營火) | ✅ | `use_item`(持盾時也能正常使用) |
| 點燃方塊(打火石/火焰彈點火、點營火、點蠟燭、點 TNT) | ✅ | `use_item`(具 5×5×5 防燒他人建物保護) |
| **刷子考古(清理可疑沙子/可疑礫石)** | ⬜ | 需要長按使用對準特定方塊持續刷取 |

## 4. 維護約定

1. **挑選實作流程**：想幫 AI 增加新能力時，從本文件挑選項目(可先看「生存進程卡點」最前面的階段) → 在 `docs/SPEC.md` 補寫技術規格與驗收條件 → 實作與測試完成後，回頭更新本文件的狀態、現況說明與進程卡點，並把開頭的「對照程式」改成重新對照時的 commit。
2. **與 `docs/REVIEW.md` 的分工**：
   - 既有功能出錯、卡住、邏輯有漏洞 → 記進 `docs/REVIEW.md`。
   - 實機試玩時發現「Minecraft 裡有這個玩法，但目前工具沒涵蓋」→ 補進本文件對應領域，供之後評估是否要挑出來做。
3. **區分 `⬜` 與 `🚫`**：`🚫` 只留給安全底線或架構原則(如管理員方塊、創造不飛、不靠截圖)；其餘尚未實作的玩法皆列為 `⬜`，隨時可挑進 `docs/SPEC.md`。
